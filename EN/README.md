# 🛡️ OverTheWire Bandit Writeups

This repository contains my complete write-ups for all levels of **OverTheWire Bandit**, a wargame focused on practical learning of Linux and security fundamentals.

---

## 📌 About the Challenge

**Bandit** is one of the most recommended challenges for beginners in cybersecurity.
It teaches, in practice, how to navigate Linux systems, manipulate files, and understand fundamental concepts used in offensive security.

---

## 🎯 Purpose of This Repository

* Document my journey completing all levels
* Consolidate my learning in Linux and security
* Build a practical cybersecurity portfolio

---

## 🧠 What I Learned

Throughout the challenges, I developed skills such as:

* Linux navigation (`cd`, `ls`, `file`)
* Reading and manipulating files (`cat`, `less`, `strings`)
* Advanced commands (`grep`, `find`, `sort`, `uniq`)
* File permissions and ownership (`chmod`, `chown`)
* Redirection and pipes (`>`, `>>`, `|`)
* Basic security and exploitation concepts
* Networking tools (`nc`, `nmap`, `openssl`, `ssh`)
* Git internals (logs, branches, tags)
* Scripting and automation (bash scripts, brute force)
